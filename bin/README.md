# 小程序下载目录

这里存放我写的一些小工具，欢迎下载使用。

## 文件列表

### PC优化大师.py
Windows 电脑清理和游戏优化工具。
- 一键清理系统垃圾文件
- 游戏优化设置
- 大文件扫描
- 图形化界面

**运行方式：** 需要安装 Python 3.x，然后双击运行或 `python PC优化大师.py`

### server-backup.py
Minecraft 服务器自动备份脚本。
- 自动备份世界文件
- 支持 zip 压缩
- 自动清理旧备份
- 可配置保留份数

**使用方法：** 修改脚本顶部的配置项，然后 `python server-backup.py`
